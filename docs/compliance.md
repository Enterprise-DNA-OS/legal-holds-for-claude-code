# Preservation record checks

Checked 30 October 2026. This software checks recorded evidence. It does not decide legal obligations, preserve source data, send notices, verify signatures or certify compliance. Counsel sets scope and timing. IT preserves the actual sources. A single confirmed source does not establish that all relevant sources were found.

| Check | Record test | Basis |
| --- | --- | --- |
| LH-01 | An unreleased hold has custodians | Local completeness policy supporting the preservation review |
| LH-02 | Each assignment has external notice evidence | Local evidence policy, not a claim that the court mandates this exact notice process |
| LH-03 | Each assignment has at least one recorded preservation confirmation | Local minimum check supporting NZ High Court Rules 8.3, not proof of sufficient preservation |
| LH-04 | Review date has not passed | Counsel-chosen local review date, not a statutory deadline |
| LH-05 | Failed, pending and older-than-30-day evidence gets attention | Local 30-day review policy, not a universal legal deadline |

NZ High Court Rules 2016, rule 8.3 requires preservation when proceedings are reasonably contemplated, including retrievable electronic records. Official source: https://www.legislation.govt.nz/regulation/public/2016/0225/latest/DLM6952386.html . Check the current rule and any case-specific directions with counsel.

AU matters are recorded with jurisdiction AU. These checks do not implement Australian court-specific rules or certify Australian compliance. Counsel must supply those requirements through /customise before operational reliance.

Activation requires recorded custodians, notice evidence and a confirmed preservation entry for every assignment. It does not send or implement anything. Release requires counsel's authority label and an evidence reference. It lists other unreleased holds for affected people and changes only the local register. It never deletes source data or removes a mailbox hold. Declared actor and counsel names are labels, not authenticated identities. Database owners can bypass controls. Preserve external evidence and control operator access.
