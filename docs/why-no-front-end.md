# A legal hold records desk without a front end

A trusted operator records the matters, people, evidence references and reviews through the agent. The database answers the weekly questions. npm run view makes read-only HTML snapshots and npm run docs makes draft paperwork using brand.json. There is no server, editable portal or browser workflow.

A custodian portal provides authenticated acknowledgements and a delivery service sends notices. Preservation integrations freeze content in its source system. This base provides none of those functions. It records evidence of work completed elsewhere. Counsel and IT continue those processes. Snapshots can become stale and are not a live service. There is no offline sync, mobile capture, drag and drop or per-user access control.

Enterprise DNA can build and test the access controls, connected preservation checks and approval process around a tailored installation. A database owner can bypass its record checks. Use one private database per business, one trusted operator and controlled backups. Do not expose this connection through a public browser API.
